# What do the lights on my ONT mean (GPON)

**Document ID:** FAQ-0023
**Category:** Frequently Asked Questions
**Applies To:** Verizon GPON Service, SFP Optical Module
**Last Reviewed:** 2025-11-14

## Summary
This FAQ addresses common customer questions regarding PPPoE authentication failure on Verizon GPON connections using a SFP Optical Module. It is intended for Tier 1 support agents and self-service customers.

## Question
What do the lights on my ONT mean (GPON)?

## Answer
Customers experiencing PPPoE authentication failure on their SFP Optical Module should first verify the physical layer before assuming a service outage. In most cases the underlying cause is related to high optical attenuation on the fiber link exceeding the -28dBm receiver threshold.

### Step-by-Step Guidance
1. Confirm all cabling (Ethernet, coax, or fiber patch cords) is fully seated at both the SFP Optical Module and the wall termination point.
2. Log into the SFP Optical Module administration portal (typically at 192.168.1.1 or 192.168.0.1) using the credentials on the device label.
3. Navigate to the Status or Diagnostics page and check for active alarms, sync rate, or optical Rx/Tx power levels.
4. If using WiFi, confirm the client is connected to the correct SSID and band (2.4GHz vs 5GHz) for the required range and throughput.
5. Power cycle the SFP Optical Module by unplugging it for 30 seconds, since this clears temporary DHCP, PPPoE, and firmware state issues.
6. If the issue persists, run a speed test via ethernet cable directly to the SFP Optical Module to rule out WiFi interference.
