# What is the difference between bridge mode and router mode (Fiber)

**Document ID:** FAQ-0067
**Category:** Frequently Asked Questions
**Applies To:** Verizon Fiber Service, WiFi 6 Router
**Last Reviewed:** 2025-11-14

## Summary
This FAQ addresses common customer questions regarding IPv6 not provisioning on Verizon Fiber connections using a WiFi 6 Router. It is intended for Tier 1 support agents and self-service customers.

## Question
What is the difference between bridge mode and router mode (Fiber)?

## Answer
Customers experiencing IPv6 not provisioning on their WiFi 6 Router should first verify the physical layer before assuming a service outage. In most cases the underlying cause is related to a failed firmware image checksum causing the device to boot into recovery mode.

### Step-by-Step Guidance
1. Confirm all cabling (Ethernet, coax, or fiber patch cords) is fully seated at both the WiFi 6 Router and the wall termination point.
2. Log into the WiFi 6 Router administration portal (typically at 192.168.1.1 or 192.168.0.1) using the credentials on the device label.
3. Navigate to the Status or Diagnostics page and check for active alarms, sync rate, or optical Rx/Tx power levels.
4. If using WiFi, confirm the client is connected to the correct SSID and band (2.4GHz vs 5GHz) for the required range and throughput.
5. Power cycle the WiFi 6 Router by unplugging it for 30 seconds, since this clears temporary DHCP, PPPoE, and firmware state issues.
6. If the issue persists, run a speed test via ethernet cable directly to the WiFi 6 Router to rule out WiFi interference.
