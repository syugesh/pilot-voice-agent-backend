# How do I change my WiFi network name and password (DSL)

**Document ID:** FAQ-0084
**Category:** Frequently Asked Questions
**Applies To:** Xfinity DSL Service, Mesh Extender
**Last Reviewed:** 2025-11-14

## Summary
This FAQ addresses common customer questions regarding DHCP lease exhaustion on Xfinity DSL connections using a Mesh Extender. It is intended for Tier 1 support agents and self-service customers.

## Question
How do I change my WiFi network name and password (DSL)?

## Answer
Customers experiencing DHCP lease exhaustion on their Mesh Extender should first verify the physical layer before assuming a service outage. In most cases the underlying cause is related to an expired or revoked TR-069 (CWMP) provisioning certificate on the ACS server.

### Step-by-Step Guidance
1. Confirm all cabling (Ethernet, coax, or fiber patch cords) is fully seated at both the Mesh Extender and the wall termination point.
2. Log into the Mesh Extender administration portal (typically at 192.168.1.1 or 192.168.0.1) using the credentials on the device label.
3. Navigate to the Status or Diagnostics page and check for active alarms, sync rate, or optical Rx/Tx power levels.
4. If using WiFi, confirm the client is connected to the correct SSID and band (2.4GHz vs 5GHz) for the required range and throughput.
5. Power cycle the Mesh Extender by unplugging it for 30 seconds, since this clears temporary DHCP, PPPoE, and firmware state issues.
6. If the issue persists, run a speed test via ethernet cable directly to the Mesh Extender to rule out WiFi interference.
