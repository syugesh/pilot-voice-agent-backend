# How do I find my account PIN for authentication (5G Home Internet)

**Document ID:** FAQ-0094
**Category:** Frequently Asked Questions
**Applies To:** Cisco TAC 5G Home Internet Service, Gateway Router
**Last Reviewed:** 2025-11-14

## Summary
This FAQ addresses common customer questions regarding double NAT causing gaming issues on Cisco TAC 5G Home Internet connections using a Gateway Router. It is intended for Tier 1 support agents and self-service customers.

## Question
How do I find my account PIN for authentication (5G Home Internet)?

## Answer
Customers experiencing double NAT causing gaming issues on their Gateway Router should first verify the physical layer before assuming a service outage. In most cases the underlying cause is related to an IPv6 prefix delegation (DHCPv6-PD) failure between the ONT and the ISP core router.

### Step-by-Step Guidance
1. Confirm all cabling (Ethernet, coax, or fiber patch cords) is fully seated at both the Gateway Router and the wall termination point.
2. Log into the Gateway Router administration portal (typically at 192.168.1.1 or 192.168.0.1) using the credentials on the device label.
3. Navigate to the Status or Diagnostics page and check for active alarms, sync rate, or optical Rx/Tx power levels.
4. If using WiFi, confirm the client is connected to the correct SSID and band (2.4GHz vs 5GHz) for the required range and throughput.
5. Power cycle the Gateway Router by unplugging it for 30 seconds, since this clears temporary DHCP, PPPoE, and firmware state issues.
6. If the issue persists, run a speed test via ethernet cable directly to the Gateway Router to rule out WiFi interference.
