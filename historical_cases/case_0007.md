# Historical Case: Case #100007 - IPv6 not provisioning

## Summary
Customer reported IPv6 not provisioning on a BT Openreach 5G Home Internet connection using a Mesh Extender. Case was resolved after 2 day(s) of investigation involving Tier 1, Tier 2, and remote network diagnostics.

## Problem Description
The customer contacted support reporting IPv6 not provisioning, which had been occurring for approximately 3 day(s) prior to the call. The customer noted the issue was present at all times of day, including overnight.

## Symptoms Observed
- Agent confirmed IPv6 not provisioning via remote diagnostics on the Mesh Extender.
- Signal/sync statistics were reviewed and found to be within normal range, pointing to a network-side cause.
- Customer-reported impact: streaming buffering and gaming lag.

## Root Cause
Investigation determined the root cause to be consistent with known patterns for IPv6 not provisioning on this device class.

## Actions Taken / Resolution
The issue was ultimately resolved by correcting an IPv6 prefix delegation misconfiguration on the OLT profile. The customer confirmed restored service with a follow-up test call 2 day(s) after the initial report, and no repeat tickets were logged in the following 30 days.
