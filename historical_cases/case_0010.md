# Historical Case: Case #100010 - Router firmware update failure

## Summary
Customer reported router firmware update failure on a Comcast Fiber connection using a SFP Optical Module. Case was resolved after 5 day(s) of investigation involving Tier 1, Tier 2, and remote network diagnostics.

## Problem Description
The customer contacted support reporting router firmware update failure, which had been occurring for approximately 1 day(s) prior to the call. The customer noted the issue was worse during evening peak hours.

## Symptoms Observed
- Agent confirmed router firmware update failure via remote diagnostics on the SFP Optical Module.
- Signal/sync statistics were reviewed and found to be outside normal operating parameters.
- Customer-reported impact: streaming buffering and gaming lag.

## Root Cause
Investigation determined the root cause to be consistent with known patterns for router firmware update failure on this device class.

## Actions Taken / Resolution
The issue was ultimately resolved by remotely resetting the PPPoE session from the BNG and confirming re-authentication succeeded. The customer confirmed restored service with a follow-up test call 5 day(s) after the initial report, and no repeat tickets were logged in the following 30 days.
