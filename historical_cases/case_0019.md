## Summary
Customer reported static IP configuration issue on a Deutsche Telekom 5G Home Internet connection using a ONT. Case was resolved after 2 day(s) of investigation involving Tier 1, Tier 2, and remote network diagnostics.

## Problem Description
The customer contacted support reporting static IP configuration issue, which had been occurring for approximately 5 day(s) prior to the call. The customer noted the issue was present at all times of day, including overnight.

## Symptoms Observed
- Agent confirmed static IP configuration issue via remote diagnostics on the ONT.
- Signal/sync statistics were reviewed and found to be within normal range, pointing to a network-side cause.
- Customer-reported impact: streaming buffering and gaming lag.

## Root Cause
Investigation determined the root cause to be consistent with known patterns for static IP configuration issue on this device class.

## Actions Taken / Resolution
The issue was ultimately resolved by re-provisioning the account after discovering a stale service profile from a prior address. The customer confirmed restored service with a follow-up test call 2 day(s) after the initial report, and no repeat tickets were logged in the following 30 days.
