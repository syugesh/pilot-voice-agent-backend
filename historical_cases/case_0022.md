# Historical Case: Case #100022 - No internet access

**Case Status:** Resolved

## Summary
Customer reported no internet access on a Verizon Fiber connection using a WiFi 6 Router. Case was resolved after 5 day(s) of investigation involving Tier 1, Tier 2, and remote network diagnostics.

## Problem Description
The customer contacted support reporting no internet access, which had been occurring for approximately 3 day(s) prior to the call. The customer noted the issue was worse during evening peak hours.

## Symptoms Observed
- Agent confirmed no internet access via remote diagnostics on the WiFi 6 Router.
- Signal/sync statistics were reviewed and found to be outside normal operating parameters.
- Customer-reported impact: streaming buffering and gaming lag.

## Root Cause
Investigation determined the root cause to be consistent with known patterns for no internet access on this device class.

## Actions Taken / Resolution
The issue was ultimately resolved by identifying a DHCP scope exhaustion on the CMTS and expanding the address pool for the node. The customer confirmed restored service with a follow-up test call 5 day(s) after the initial report, and no repeat tickets were logged in the following 30 days.
