# Historical Case: Case #100057 - Wireless client authentication timeout

**Document ID:** CASE-0057

**Case Status:** Resolved

## Summary
Customer reported wireless client authentication timeout on a Airtel DSL connection using a Gateway Router. Case was resolved after 4 day(s) of investigation involving Tier 1, Tier 2, and field dispatch.

## Problem Description
The customer contacted support reporting wireless client authentication timeout, which had been occurring for approximately 3 day(s) prior to the call. The customer noted the issue was present at all times of day, including overnight.

## Symptoms Observed
- Agent confirmed wireless client authentication timeout via remote diagnostics on the Gateway Router.
- Signal/sync statistics were reviewed and found to be within normal range, pointing to a network-side cause.
- Customer-reported impact: unable to work from home / VoIP calls dropping.

## Root Cause
Investigation determined the root cause to be consistent with known patterns for wireless client authentication timeout on this device class.

## Actions Taken / Resolution
The issue was ultimately resolved by correcting an IPv6 prefix delegation misconfiguration on the OLT profile. The customer confirmed restored service with a follow-up test call 4 day(s) after the initial report, and no repeat tickets were logged in the following 30 days.
